# Tilak Teja Kampati — Portfolio

A colourful, responsive MIS Analyst portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — visual theme, responsive layout and animations
- `script.js` — mobile navigation, reveal animations and project case-study popups
- `assets/` — place your profile photo and project screenshots here

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing — personalize these items
1. Replace the profile-photo placeholder with your professional photo.
2. Replace `your.email@example.com` with your email address.
3. Add your actual LinkedIn and GitHub profile URLs.
4. Add your WhatsApp link if you want it displayed.
5. Put your latest resume PDF in this folder and name it `resume.pdf`.
6. Replace the illustrative dashboard mockups with screenshots of your actual Excel/Power BI projects.
7. Verify the experience dates and wording match your exact employment history.

The project cards currently describe portfolio/practice work and should not be presented as employer deliverables unless that is accurate.
